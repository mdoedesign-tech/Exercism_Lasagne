# Guido's Gorgeous Lasagna

A beginner-friendly Python exercise focused on functions, variables, and docstrings.

## About

This project is part of my Python learning journey on  
[Exercism.org]

The exercise is based on preparing Guido's famous lasagna and practices core Python concepts such as:
- functions
- parameters
- return values
- constants
- docstrings
- basic calculations

## Features

The program includes functions for:
- calculating remaining bake time
- calculating preparation time
- calculating total elapsed cooking time

## Technologies

- Python 3

## What I learned

- Creating and using functions
- Working with constants and variables
- Writing clean and readable code
- Using docstrings for documentation
- Performing simple mathematical calculations
- Structuring Python modules

## Example

```python
bake_time_remaining(30)
# Returns: 10

preparation_time_in_minutes(3)
# Returns: 6

elapsed_time_in_minutes(3, 20)
# Returns: 26
```
